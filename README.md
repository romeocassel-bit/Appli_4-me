# Appli 4e — prototype pédagogique

Application web d'accompagnement scolaire destinée à une élève de 4e. Séances courtes (5, 10 ou 15 minutes), lectures, orthographe, mathématiques, découverte historique et révisions espacées.

## Objectifs

- Ne pas ajouter de pression après une longue journée de cours.
- Soutenir la lecture plaisir, la compréhension, les automatismes et la mémorisation.
- Expliquer les erreurs, proposer des indices et valoriser les progrès personnels.
- Prévoir plusieurs matières avec un seul moteur de rappel.

## État

Prototype initial en préparation sur une branche séparée. Aucune donnée d'enfant, aucun diagnostic, aucun service distant dans ce premier prototype. Les contenus sont des exemples à valider avant usage réel.
