# Déploiement du prototype

Le code de l'application se trouve sur la branche `prototype-v1` : `index.html`, `styles.css`, `app.js`.

Sur Vercel :
1. Choisir `prototype-v1` comme branche de production.
2. Régler le framework sur `Other`, avec le répertoire racine du dépôt.
3. Un nouveau commit sur cette branche doit déclencher un déploiement si l'intégration GitHub/Vercel est active.
4. Vérifier dans `Deployments` que la source indique `prototype-v1` et que le statut est `Ready`.

Ne pas publier de données personnelles d'une mineure dans le prototype.
